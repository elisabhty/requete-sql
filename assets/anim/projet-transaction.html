TRANSACTION
Valider les modifications ensemble
Regroupe plusieurs modifications pour les valider ensemble ou toutes les annuler.
Les trois idées à retenir
🚦
BEGIN TRANSACTION démarre la transaction.Selon le SGBD, tu peux aussi écrire
BEGIN ou START TRANSACTION.
✅
COMMIT valide toutes ses modifications.Elles deviennent définitives,
et la transaction se termine.
↩️
ROLLBACK annule toutes les modifications
non validées de la transaction.Après COMMIT, tu ne peux plus utiliser
ROLLBACK pour annuler cette transaction.
