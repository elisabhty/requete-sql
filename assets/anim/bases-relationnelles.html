Les trois idées à retenir
🗂️
Une table range un sujet : clients, produits, commandes.Ses colonnes sont des caractéristiques, ses lignes des enregistrements.
🔑
Une clé primaire (PRIMARY KEY) identifie chaque ligne ; une clé étrangère renvoie vers celle d’une autre table :
FOREIGN KEY (client_id)
  REFERENCES clients(id)
📋
SELECT choisit les colonnes à afficher, séparées par une virgule ; l’étoile * les prend toutes :
SELECT prenom, nom, email
