Les trois idées à retenir
🗂️
Une table range un sujet : clients, produits, commandes.Ses colonnes sont des caractéristiques, ses lignes des enregistrements.
🔑
Une clé primaire identifie une ligne ; une clé étrangère renvoie vers la clé primaire d’une autre table.
👀
SELECT lit les données d’une table, sans jamais les modifier :
SELECT * FROM clients;
