🎯Un total progressif, commande après commande
requete.sql
WITH montants AS ( SELECT commandes.id, commandes.date_commande, produits.prix * commandes.quantite AS montant FROM commandes JOIN produits ON produits.id = commandes.produit_id)SELECT date_commande, montant, SUM(montant) OVER ( ORDER BY date_commande, id ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW ) AS cumulFROM montantsORDER BY date_commande, id;
Exécuter
SUM(montant) OVER (AVG(montant) OVER ( ORDER BY date_commande, id ROWS BETWEEN UNBOUNDED PRECEDING2 PRECEDING AND CURRENT ROW) AS cumul) AS moyenne_3

Les trois idées à retenir
🪟
Le cadre de fenêtre indique les lignes utilisées pour calculer la ligne actuelle :
ROWS BETWEEN début AND fin
💰
Un cumul : le cadre part du début et s’agrandit jusqu’à la ligne actuelle :
UNBOUNDED PRECEDING AND CURRENT ROW
📊
Une moyenne mobile : le cadre se déplace sur quelques lignes.Ici, la commande actuelle et les 2 précédentes.2 PRECEDING AND CURRENT ROW
