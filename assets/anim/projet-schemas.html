SCHÉMAS
Ranger les tables par espace
Organise les tables d’une grande base en espaces distincts grâce aux schémas.
Les trois idées à retenir
🗂️
Un schéma range les tables
d’une base en espaces.CREATE SCHEMA boutique;
crée l’espace de la boutique.
📍
boutique.commandes est
une adresse : schéma.table.Deux schémas peuvent contenir
deux tables qui portent le même nom.
⚠️
Les schémas dépendent du SGBD.SQLite n’a pas de CREATE SCHEMA :
ses tables sont rangées dans main.
