DROP
Supprimer une table
Une table est de trop dans la base :
à toi de la retirer.
Les trois idées à retenir
🗑️
DROP TABLE supprime toute la table :
ses lignes et ses colonnes.DELETE FROM sans WHERE supprime
toutes les lignes, mais conserve la structure.
🔗
Une clé étrangère peut bloquer la suppression
si une autre table fait référence à celle-ci.Vérifie toujours le nom de la table
avant de la supprimer.
🛟
IF EXISTS évite une erreur
si la table n’existe pas.Il ne protège pas contre la suppression
de la mauvaise table.DROP TABLE IF EXISTS inscriptions_excel;
