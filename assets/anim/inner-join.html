Les trois idées à retenir
🤝
INNER JOIN combine les données de deux tables en conservant uniquement les lignes qui ont une correspondance dans l’autre table.Chaque paire de lignes correspondantes donne une ligne dans le résultat.
🔗
ON définit la condition qui permet d’associer les lignes des deux tables :
ON commandes.client_id = clients.id
🔎
WHERE filtre le résultat de la jointure pour ne garder que les lignes qui respectent une condition.
