Les trois idées à retenir
🧹
DISTINCT retire les doublons.Il agit sur le résultat, sans modifier la table.
📍
Il se place juste après le SELECT :
SELECT DISTINCT ville
🧩
Avec plusieurs colonnes, il compare la combinaison entière des valeurs :
SELECT DISTINCT ville, prenom
