Les trois idées à retenir
🔎
EXPLAIN QUERY PLAN montre comment
la base prévoit d’exécuter une requête.SCAN : la table est parcourue ;
SEARCH … USING INDEX : l’index est utilisé.
⚡
Un index permet de retrouver plus
rapidement les lignes à partir
d’une valeur recherchée.Ici, le numéro de la commande
sert à la retrouver.
⚖️
Un index a un coût : il occupe de l’espace
et doit être entretenu
lorsque les données changent.Crée-les pour les recherches
qui en ont besoin.
