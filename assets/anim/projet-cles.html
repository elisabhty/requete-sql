Relier les tables entre elles
Tes tables sont prêtes :
à toi de les relier avec des clés.
Les trois idées à retenir
🔑
La clé primaire identifie chaque ligne
d’une table. Elle est unique
et ne peut pas être vide (NULL).
🔗
La clé étrangère fait référence à une clé
d’une autre table pour relier les données.
🔀
Les relations peuvent être de trois types :1 ↔ 1 : une clé étrangère unique.1 → N : une clé étrangère du côté « plusieurs ».N ↔ N : une table d’association,
avec une ligne par lien.
