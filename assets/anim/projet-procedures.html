PROCÉDURES
et fonctions stockées
Enregistre des actions et des calculs dans la base pour pouvoir les réutiliser.
Les trois idées à retenir
🛠️
Une procédure stockée exécute
un traitement réutilisable.Tu l’appelles avec CALL :
CALL expedier_commande(13);
🧮
Une fonction stockée renvoie
un résultat réutilisable.Tu l’utilises dans une requête :
SELECT calculer_points(80);
⚠️
Leur syntaxe dépend du SGBD.Les deux reçoivent des paramètres.
SQLite, la base de l’app, n’en a pas.
