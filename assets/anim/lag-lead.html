SELECT client_id, date_commande, LAG(date_commande) OVER ( PARTITION BY client_id ORDER BY date_commande, id ) AS precedenteFROM commandesWHERE client_id IS NOT NULLORDER BY client_id, date_commande, id;

WITH delais AS ( SELECT client_id, julianday(date_commande) - julianday(LAG(date_commande) OVER ( PARTITION BY client_id ORDER BY date_commande, id )) AS jours_depuis FROM commandes WHERE client_id IS NOT NULL)SELECT clients.prenom, clients.nom, COALESCE(AVG(jours_depuis), 10) AS delai_moyenFROM delaisJOIN clients ON clients.id = delais.client_idGROUP BY clients.idORDER BY clients.id;

LAG() lit une valeur sur la ligne précédente, LEAD() sur la suivante.
LAG(date_commande) OVER (…)
🧭
PARTITION BY sépare les groupes ; l’ORDER BY de OVER définit ce qui vient avant ou après.Sans PARTITION BY : une seule suite.
🕳️
Au bord de la fenêtre, il n’y a pas de voisine : le résultat vaut NULL.AVG() ignore les NULL ; COALESCE() fixe une valeur par défaut.
