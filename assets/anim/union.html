Les trois idées à retenir
📚
UNION empile les lignes de deux SELECT et écarte les doublons ; UNION ALL les garde tous.
SELECT … UNION SELECT …
📏
Les deux requêtes doivent avoir le même nombre de colonnes.Leurs noms viennent de la première requête.
🧠
Un moyen simple de s’en souvenir : JOIN élargit, UNION rallonge.
