Les trois idées à retenir
✂️
LIMIT n garde les n premières lignes du classement :
ORDER BY prix DESC LIMIT 3
⏭️
OFFSET n saute n lignes. Pour la page p : (p − 1) × taille.
LIMIT 3 OFFSET 3
🔒
Un classement stable : termine ORDER BY par une colonne unique :
ORDER BY prix DESC, id
