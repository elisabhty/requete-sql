ALTER
Faire évoluer les tables
Les ateliers ont commencé :
à toi d’adapter les tables sans les recréer.
Les trois idées à retenir
🛠️
Modifier une tableALTER TABLE permet d’ajouter, de renommer ou de supprimer une colonne d’une table existante.
➕
Ajouter une colonneAvec ADD COLUMN, les lignes déjà présentes
reçoivent la valeur définie par DEFAULT,
ou NULL si aucune valeur par défaut
n’est prévue et que la colonne l’autorise.
🔄
Distinguer structure et valeursALTER TABLE modifie la structure ;
UPDATE modifie les valeurs.
Renommer une colonne conserve son contenu.
La supprimer efface toutes
les données de cette colonne.
