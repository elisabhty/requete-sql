Les trois idées à retenir
🔎
LIKE vérifie si le texte correspond au motif : c’est le pattern matching.
WHERE prenom LIKE 'L%'
🧵
% est un wildcard : il remplace n’importe quelle suite :
LIKE '%ie%'
☝️
_ est également un wildcard : il remplace un seul caractère :
LIKE '_a%'
