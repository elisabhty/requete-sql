⚠️NULL ou texte vide ?
COALESCE(NULL, 'Non renseigné')→Non renseigné
NULL : aucune valeur, elle est remplacée.
COALESCE('', 'Non renseigné')→
'' : un texte de zéro caractère, il est gardé.
✕
La case reste videUn texte vide n’est jamais remplacé.
requete.sql
SELECT prenom, COALESCE(email, 'Non renseigné') AS emailFROM clients;

Les trois idées à retenir
🥇
COALESCE renvoie la première valeur qui n’est pas NULL :
COALESCE(email, 'Non renseigné')
🪞
Il change l’affichage, pas la table :
l’email de Hugo Laurent reste NULL.
⚠️
Un texte vide '' n’est pas NULL : COALESCE ne le remplace pas.
