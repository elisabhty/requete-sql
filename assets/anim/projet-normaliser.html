Les trois idées à retenir
📋
Un tableur qui mélange les sujets
recopie les informations : modifier,
supprimer ou ajouter devient risqué.
🗂️
Normaliser, c’est écrire une seule fois
chaque information, dans la table
de ce qu’elle décrit.
📝
Une information qui décrit un lien,
comme la date d’inscription,
va dans la table de ce lien.
