ONDELETE
Le sort des lignes liées
Un compte ne peut pas être supprimé :
à toi de décider du sort des lignes liées.
Les trois idées à retenir
🛑
Sans règle, la suppression d’une ligne
encore désignée est refusée.Le message d’erreur est
FOREIGN KEY constraint failed.
🔀
ON DELETE choisit le sort
des lignes liées.CASCADE les supprime, SET NULL les détache,
RESTRICT refuse la suppression.
📍
La règle se déclare dans CREATE TABLE,
jamais dans le DELETE.Elle se place à côté de la clé étrangère :
REFERENCES clients(id) ON DELETE SET NULL.
