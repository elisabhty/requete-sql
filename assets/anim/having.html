Les trois idées à retenir
🧮
HAVING conserve les groupes qui respectent une condition.Exemple : HAVING COUNT(*) >= 2 garde les groupes d’au moins 2 lignes.
🔀
WHERE sélectionne les lignes avant de former les groupes.
🚫
Pour filtrer sur COUNT(*), utilise HAVING.Au moment du WHERE, le comptage par groupe n’a pas encore été effectué.
