Modifier des lignes
Les informations changent :
à toi de les modifier dans la base.
Les trois idées à retenir
✏️
Modifier des données existantesUPDATE modifie les valeurs de lignes déjà présentes. SET précise les colonnes à modifier et leurs nouvelles valeurs ; WHERE sélectionne les lignes concernées.
⚠️
Vérifier les lignes avant de modifierSans WHERE, la modification s’applique
à toute la table. Avant d’exécuter
ton UPDATE, vérifie les lignes ciblées
avec un SELECT utilisant le même WHERE.
🔢
Calculer une nouvelle valeurTu peux partir de la valeur actuelle, par exemple pour ajouter 2 séances. La nouvelle valeur doit respecter les règles de la table, sinon la modification est refusée.
