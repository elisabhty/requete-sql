Les trois idées à retenir
🧵
GROUP_CONCAT rassemble les valeurs d’un groupe dans une seule cellule :
GROUP_CONCAT(id, ', ')
✂️
Le séparateur suit la colonne : sans lui, une virgule seule.Les valeurs NULL sont ignorées.
↕️
Pour trier les valeurs, place ORDER BY dans la fonction :
GROUP_CONCAT(id, ', ' ORDER BY id DESC)
