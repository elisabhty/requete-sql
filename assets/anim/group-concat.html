Les trois idées à retenir
🧵
GROUP_CONCAT() réunit les valeurs d’un groupe dans une seule cellule.
GROUP_CONCAT(id, ', ')
✂️
Le séparateur se précise
après la colonne.Par défaut, les valeurs sont séparées par une virgule sans espace.
Les valeurs NULL sont ignorées.
↕️
Pour trier les valeurs
dans chaque liste, place ORDER BY
à l’intérieur de la fonction.
GROUP_CONCAT(id, ', ' ORDER BY id DESC)
