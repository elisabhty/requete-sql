CREATE
Les tables des ateliers
Le plan est prêt : à toi de construire
les tables avec CREATE TABLE.
Les trois idées à retenir
🏗️
1. Créer une tableCREATE TABLE définit son nom et ses colonnes.
Pour y ajouter des lignes, on utilise INSERT INTO.
🔤
2. Définir les colonnesChaque colonne possède
un nom et un type de données.
Par exemple, seances INTEGER permet de stocker un nombre entier de séances.
🛡️
3. Définir les règlesLes contraintes encadrent les données :
identifiant unique (PRIMARY KEY),
valeur obligatoire (NOT NULL),
absence de doublons (UNIQUE),
condition à respecter (CHECK)
et relation avec une autre table (FOREIGN KEY).
