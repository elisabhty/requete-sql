Les trois idées à retenir
🧺
GROUP BY rassemble les lignes qui ont la même valeur :
GROUP BY ville
🧮
Chaque groupe reçoit un calcul : COUNT, SUM, AVG, MIN ou MAX.
🚫
Le SELECT n’affiche que la colonne du GROUP BY ou un calcul :
SELECT ville, COUNT(*)
