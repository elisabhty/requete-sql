Avant de commencerC'est quoi une base de données ? 2 min

Imagine un classeur Excel. Chaque feuille s'appelle ici une table : une pour les clients, une pour les produits, une pour les commandes.

idnomville
1SophieParis
2LucasLyon
↑ les colonnes = les types d'info← les lignes = les enregistrements

Une colonne décrit une information (le nom, la ville). Une ligne est un enregistrement complet : un client, avec toutes ses infos.

Le SQL est la langue qu'on utilise pour poser des questions à ce classeur. Tu écris une phrase, la base te renvoie un tableau de réponses.

À retenir : un SELECT ne modifie jamais tes données. Tu peux te tromper autant que tu veux, rien ne casse.
